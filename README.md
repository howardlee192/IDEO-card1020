## 🎴 卡牌格式標準（對標 IDEO 實體卡）

每張卡片嚴格遵循 IDEO 官方卡牌格式，拒絕抽象空話，直擊製作痛點：

* **頂部分類欄**：標註 `Learn · Look · Ask · Try` 當前認知與行動維度。
* **正面配圖指示**：具象實物情境（如微距材質、秒表、剪刀等真實道具）。
* **HOW（如何做）**：1 句話具體操作指令。
* **WHY（為何做）**：1 句話直指解決的製作痛點或核心效益。
* **案例（EXAMPLE）**：真實動畫現場危機解決案例。

## 👥 5 人小團隊兼任矩陣 (5-Person Team Matrix)

* **成員 A（主導）**：編導（劇本 / Picture Lock）＋ 剪輯與聲音
* **成員 B（主視覺）**：概念設計（色彩腳本 / 角色場景設定）＋ 背景繪製
* **成員 C（動態核心）**：分鏡 / 動態腳本 (Animatic) ＋ 關鍵原畫
* **成員 D（動態執行）**：動畫師（原畫 / 中割 / 清線著色資產化）
* **成員 E（後期基石）**：特效與合成（圖層管理 / 2D 特效 / 全片調色母帶）
